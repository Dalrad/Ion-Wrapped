# Pilot Recap 2026

A static page where pilots look up their recorded 2026 ship sinks, losses, ground kills, levels and rankings by in-game name. Results come only from parseable events in an archived channel export and are not a complete account history.

The page is plain HTML, CSS and ES modules in [`site/`](./site). There is no build step and no runtime dependency.
